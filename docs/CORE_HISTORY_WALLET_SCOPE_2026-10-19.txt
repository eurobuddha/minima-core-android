Implementation

addresses, chooses matching foreign counterparty rather than first/change output,
and only marks Split/Consolidation when every input/output belongs to Core and net
is zero. Foreign tracked activity is never marked a Core split. State-field mine
flags remain filtering metadata, not authority to count funds as Core-owned.
Native stored coin amounts are exact, so existing1000 transfer records are repaired
transactionally before list/search/CSV/JSON export. IDs, coin evidence and timestamps
are retained. Node sync can refresh existing valid records without counting them as
new; import dedup remains unchanged. Fresh token records preserve tokenamount display
units. Legacy token rows without unit metadata are not guessed; a fresh node record
is required to recalculate them. Missing ownership/malformed coin data cannot prove
a split. Canonical adapter regenerates all source changes from the pinned snapshot.
