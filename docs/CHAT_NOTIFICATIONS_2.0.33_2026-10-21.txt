What 2.0.33 changes (core app module, hand-edited; no adapter-generated file touched):
1. ChatDrainer.createChannel(Context): channel id MinimaChatChannel_v2 (sound is frozen after a
   channel is created, hence the new id; v1 is deleted), IMPORTANCE_HIGH, vibration on, badge on,
   sound android.resource://<pkg>/raw/pssst (res/raw/pssst.wav copied byte-exact from Parlons,
   sha256 ce3d5b223a545d472b183362bf04014badb99a680b047a93f13f6e8e3a7e82bb). The URI is
   name-based; AAPT shortens the path inside the APK (res/Hg.wav) but keeps the name in
   resources.arsc. MinimaService creates the channel before the keets gate, so Parlons
   (MaxChatNotifier, same channel) has it even with keets disabled.
2. Pssst.ensureAudible (ported from Parlons, no pref gate): raises the notification stream to
   2/3 when it is below half, only in RINGER_MODE_NORMAL, never lowers it.
3. ChatThreadActivity.sForegroundPubkey: no notification while that thread is on screen; opening
   a thread cancels the "keetchat" notification.
4. Chat tab banner "Notifications are off. Tap to turn them on." (four languages) when the app's
   notifications are disabled or the chat channel is set to NONE; tap opens the app's system
   notification settings.
5. MainActivity requests POST_NOTIFICATIONS on its own (request 98) on Android 13+ instead of
   inside the storage-permission batch that never completes there.
6. Diagnostics: "[CHAT] notifications enabled=.. channel importance=.. sound=.." once at channel
   creation and "[CHAT] notify posted from=<full pubkey> fresh=N" after every post.
