Hosting byte-range verification repair — 1.9.94/code165

Summary

the server returned only two bytes of the gzip representation. Android cannot
decode that truncated stream. The existing verifier now requests identity encoding
alongside Range: bytes=0-1 on every redirect hop, in both Atelier and Salon.
